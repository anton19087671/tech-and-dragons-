ВЫДЕЛЕННЫЙ СЕРВЕР TECH & DRAGONS (Forge 1.20.1-47.4.28)

Нужен только если вы хотите отдельный сервер. Для игры через Porthole
(хост открывает мир для сети) этот архив не нужен.

1) Установите Java 17 (Adoptium Temurin 17 или Oracle JDK 17).
2) Распакуйте архив в пустую папку и запустите 1_install_forge.bat.
3) Скопируйте папку mods из клиентского архива Tech-and-Dragons сюда.
4) Запустите 2_remove_client_mods.bat — он удалит 12 клиентских модов
   (список в client-only-mods.txt).
5) Запустите run.bat (его создаст установщик). При первом запуске сервер
   остановится и попросит принять EULA: откройте eula.txt и поставьте
   eula=true (это ваше согласие с лицензией Minecraft), запустите снова.
6) server.properties уже настроен: online-mode=false (для TLauncher),
   2 игрока, прорисовка 8, симуляция 6. Память — user_jvm_args.txt (6 ГБ).
7) Папка kubejs уже содержит баланс рецептов и выдачу книги-путеводителя
   при первом входе. Мод книги (tdguide-2.0.0.jar) приходит вместе с mods.
8) Рекомендуется заранее сгенерировать мир: в консоли сервера
   chunky radius 2000, затем chunky start (около часа).
